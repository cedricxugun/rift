# 吞城：裂隙远征 · Riftbound

V7 离线网页 Demo，面向 iPhone 竖屏。控制一座有生命的吞噬城堡，收集物资、改装技能、躲避危险，再迎战风铃草甸的守卫与空洞树王。关卡时钟约 10–12 分钟；子弹时间会拉长实际游玩时间。

## 手机公开网页版

[直接打开手机试玩](https://riftbound-mobile-v7.boydwilkinsontfo.chatgpt.site)，无需游戏账号。使用全屏游戏入口，手机不显示演示机框。已检查 375×667、393×852 竖屏和 852×393 横屏，适配安全区、三选一和多指触控。首次加载约 20 MB 美术与脚本，图片使用独立缓存；存档在当前浏览器保存。

发布平台已确认部署成功及公开权限；本机匿名脚本复核被 Cloudflare 拦截，未绕过拦截，未声称完成真机联网验证。部署记录见 research/mobile-web-deployment.json。`bun run build:mobile` 生成 .sites/riftbound-mobile/dist；`bun run preview:mobile` 仅启动本地预览。

## 直接游玩

双击 **iPhone-Demo.html** 或 **开始游戏.cmd**。标题应显示 **V7**；已打开的旧页面需要刷新。**Riftbound.html** 是全屏单文件版本，**Riftbound-v7-offline.zip** 是包含源码和素材的离线包。三个独立 HTML 均内嵌素材、脚本、六语文案和合成音频，不需要联网或安装依赖。

- WASD / 方向键移动，鼠标按住拖动，或触屏摇杆。
- 空格、右键或右下时钟：子弹时间，持续 4 秒、世界 20% 流速、从开启时计 24 秒冷却，仍会受伤。
- P / Esc 暂停。底部技能卡查看升级路线；右上小按钮查看组合、缺少的组件和本局伤害分布。
- 开始菜单的“起始城堡 / 查看区别”解释三种开局，“城体与武器成长”可切换炮阵、军团、园庭预览。

**HTTP 试玩：** 双击 **打开网页试玩.cmd**，启动或复用本机 `http://127.0.0.1:4177/iphone.html`。需要 Bun 或 Node；缺少运行时时退回独立 HTML。**真机 Safari：** 电脑与手机同一 Wi-Fi，运行 **iPhone试玩.cmd**，使用窗口显示的局域网地址。存档按浏览器和访问地址分别保存。

## V7：让组合改变打法，让城堡体现装备

现在共有 **7 类战斗技能、40 阶技能成长、13 个自动联动组合、29 项通用强化、4 类精英、三阶段 Boss**。本次增加召唤和地面控制，并把学习提示、城体硬件、攻击来源、伤害记录接到同一套实际技能上。

| 路线 | 战斗方式 | 城堡上能看到什么 |
| --- | --- | --- |
| 炮击 | 远程打阵线；冰霜先减速，炮击触发冰爆；攻城姿态奖励短暂停步 | 单炮、双炮、三炮组；回收齐射分支安装三炮，弹丸从对应炮口发出 |
| 橡实军团 | 护卫追击、近战横扫、拦弹；吞物资集结；雷电连线或花园围猎 | 单铃、双铃、三铃召唤门；护卫从门口出现，军团之心在集结期间产生重型队长 |
| 荆棘花园 | 移动沿路播种，站定后在敌人脚下种植；诱导追兵入园；搭配冰或火改变绽放 | 单种荚、多种荚、大型种植台；种子从架上抛向实际种植点 |

保留三种起始城堡的四档独立城体：I 流浪小屋、II–III 武装宅邸、IV–V 行走要塞、VI 巡游巨城。吞噬扩建城体，技能等级改变装备，分支改变对应武器；学习冰霜不会额外长出一座冰霜城堡。副武器按学习顺序保留安装平台，学雷电不会把原有召唤门移到另一侧。组合成立后出现连接设备的管线，实际触发时产生脉冲。

### 新的组合目标

| 组合 | 前置 | 玩家要做什么 |
| --- | --- | --- |
| 雷网军团 | 军团 2 + 雷电 1 | 吞物资或开启子弹时间触发集结，让护卫的导电阵线穿过敌群 |
| 林庭伏击 | 军团 2 + 花园 2 | 先种撤退路线，再引怪入园；护卫优先围攻被根须减速的目标 |
| 霜棘禁域 | 花园 2 + 冰霜 2 | 绕花园控住追兵，根须绽放施加冰霜并造成范围伤害 |
| 焚林果园 | 花园 2 + 烈焰 2 | 让火球点燃花园，后续绽放变为火焰爆破 |
| 冰川炮阵 | 火炮 2 + 冰霜 2 | 减速前排后炮击触发范围冰爆，同一目标每秒最多一次 |
| 暴雪护环 | 风暴 2 + 冰霜 2 | 靠近敌群触发风压冻结，并清除有限敌弹 |

原有回收旋风、雷鸣炮阵、冰火冲击、风暴导流、火焰龙卷、棱光放电、陨星熔炉仍保留。组合页优先展示当前可达路线，其他组合折叠；记录实际伤害和连携命中，不把配置数字当作伤害结果。

护卫有生命、受击间隔和 6 秒重召时间，拦弹消耗自己的生命。军团 1–5 阶对应 2 / 3 / 3 / 4 / 5 名护卫；繁育旗帜可再加 1 名，上限 6。花园最多同时 4 处，4 阶后 6 处；2 阶解锁减速，3 阶短暂定身普通敌人，5 阶才解锁子弹时间唤醒全部花园。精英与 Boss 保留控制抗性。

## 吞噬、选卡与阶段节奏

**吞噬填能量 → 出现技能遗迹 → 吞下遗迹 → 暂停横排三选一。** 三张卡区分武器、召唤、地面、战术、数值和核心；显示升级幅度、稀有度、组合缺项和是否立即解锁。每局 3 个战斗技能槽 + 1 个核心，2 次免费重选。最初两轮有机会优先接触召唤或花园；已投入的组合临近成型时，缺少的升级优先进入候选。第五次选择起提供起始城堡分支，第八次起可遇到对应精通。

洞口大小决定能吞什么；护盾、锚定和体型会阻止直接吞噬。长大后仍持续自动攻击。敌人变成残骸后可以吞下，给技能能量和城堡蓄能。受击区是可见的能量中枢，随城堡成长扩大，和整座城堡的装饰轮廓分开。

- 前 22 秒是吞物资的开场；前 7 秒不弹出技能选择。出生地、堆叠物资和稀有开局物件按种子变化。
- 普通交战按 40 秒进攻 / 8 秒停刷新交替。22–40 秒每批 2 个，40–90 秒每批 3 个，90–270 秒 4 个，之后 5 个；在场上限分别为 10 / 14 / 22 / 30。个体强度按关卡时间成长，不因刚学到技能立即涨血。
- 1:30、4:30、7:30 安排精英，10:00 安排 Boss。当前特殊战斗未结束时，后续特殊战斗等待。
- **精英 / Boss 登场时普通敌人撤离，清掉旧敌弹与危险，不再生成普通敌群或事件守卫。** 撤离不给击杀奖励。击败精英后有 8 秒收集空档；登场前 18 秒不再开启新地图事件。
- 特殊敌人部分招式后掉落少量可吞矿料，维持吞噬蓄能循环；这些不是回血包。Boss 低于 32% 进入第三阶段，到 12% 才破壳并允许体型足够的城堡吞噬终结。

四类精英分别是角卫（横扫、齐射、锁定冲锋）、先知（扫射、花环、交叉射线）、荆棘园丁（根墙、扫枝、正反震波、崩落区）、铃翼母蛾（翼斩、花瓣陷阱、锁定俯冲）；每局三场按种子轮换。Boss 有横扫、追身根刺、旋转射线、正反震波、交叉根墙和花瓣弹环，阶段增加组合招式。本次没有提高三场精英的 6000 / 18000 / 30000 生命和 Boss 的 90000 生命。

## 恢复与局外成长

普通战斗击杀累计 12 次、间隔 28 秒才掉基础 14 点血包；生命不高于 40% 时为 6 次 / 18 秒，高于 85% 停止普通掉落。普通包最多 2 个，连同保证奖励总计最多 3 个。直接吞未受伤、未破盾的小怪不刷药。精英掉基础 30 点包，地图另有少量一次性恢复建筑；必须走过去吞，满血时保留。

结束远征获得零件，可改装基础移动速度、装甲、吞噬牵引和恢复效果。局内技能与分支每局重置。移动速度卡、军团步调和精英动力改良分别服务于城堡机动、护卫进攻和吞噬蓄能，避免所有升级都只加伤害。

## 验证与已知范围

本版 **122 项规则测试通过，839 个词条的六语校验通过**，构建产物已核对。Chrome 普通键盘、移动、选卡实玩了两个构筑：雷网军团完成第一场精英与城市改良；霜棘禁域实际形成花园冰爆并显示 4 次连携命中。最终成长图鉴在 394×852 和 314×682 实际 CSS 视口检查，游戏错误日志和图集问题列表为空。浏览器扩展自身的警告未计为游戏错误。

这是两条早期构筑的实玩验证，**本轮没有完整手玩到最终 Boss**。第一精英在军团成型后仍结束较快，后期数值、持续压力和最优组合仍需完整人工测试。军团实玩候选早于最终阵线去重、波次密度、地图事件避让和平台固定修正；花园实玩使用后续候选。详细证据、区别与设计取舍在 [V7 构筑、城堡与对决设计](research/V7-构筑城堡与对决设计.html)。

Chrome 工具复测使用 localhost 提供的同一内嵌 HTML；受工具对 file:// 的限制，没有将此次验证描述成直接双击启动或实体 iPhone 性能测试。离线包内容及无外部资源依赖另作静态核对。

## 美术与实现

运行时 14 张图集。V7 新增原创橡实护卫、树卫、召唤门、种荚架、园丁、母蛾、树王动作和根须爆发；沿用原有城体与场景的手绘线条、自然配色。内置 image_gen 生成的 PNG 原稿、提示词、来源和无损 WebP 对照见 [V7 素材清单](assets/builds-v7-manifest.json)；此前城体四阶段素材见 `assets/castle-growth-v65-manifest.json`。没有使用参考游戏的原始美术或代码作为运行素材。

```powershell
bun install
bun run i18n:sync
bun test
bun run build
bun run serve
```

- `src/v2/game.js` / `data.js`：成长、选卡、掉落、关卡和敌人 AI。
- `formations.js` / `formation-visuals.js`：护卫、花园及其战斗表现。
- `arsenal.js` / `route-mechanics.js`：技能组合、吞噬蓄能和主武器。
- `enemy-patterns.js` / `hazards.js`：特殊招式、共享预警与命中几何。
- `castle-appearance.js` / `weapon-rig.js` / `sprites.js`：城体档位、装备平台、炮口和图集绘制。
- `ui.js` / `style.css`：三选一、组合图鉴、手机 HUD 和城堡预览。
- `scripts/add-v7-keys.mjs`：V7 六语翻译源，统一经 `i18n:sync` 生成。

旧浏览器和模拟驾驶脚本保留在 `scripts/`，并未作为本版“普通玩家实玩”证据。它们可用于流程回归，不能证明难度有趣。V1 源码留作历史对照；当前构建入口是 `src/v2/main.js`。
