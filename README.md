# 吞城：裂隙远征 · Riftbound V8

iPhone 竖屏优先的离线网页游戏。吞物资与战斗残骸积攒技能能量，吞下遗迹后横排三选一；用三种战斗技能、一个核心和城堡分支组成构筑。第一关是风铃草甸，场景和敌人遵循草甸主题，玩家装备可以跨体系混搭。

## 游玩

[公开手机试玩](https://riftbound-mobile-v7.boydwilkinsontfo.chatgpt.site)沿用原链接，菜单版本为 **V8**。手机入口直接全屏运行；不套演示机框。首次资源约 22 MB，后续使用独立文件缓存。无游戏账号、无后端存档，进度保存在当前浏览器。

电脑双击 **Riftbound.html** 全屏游玩，或 **iPhone-Demo.html** 查看交互式手机演示。**Riftbound-v8-offline.zip** 包含独立 HTML、源码、素材和设计记录。离线 HTML 内嵌图片、脚本、六语文案与合成音效。WASD / 方向键移动，空格开启子弹时间，P 暂停；手机拖动摇杆、点击时钟。

## V8：改变打法的蓝图

七类基础技能保留阶级成长；新增八种改装形态，每种武器只能选一种蓝图。机库使用独立机械装置与无人机，火焰、雷电、冰霜、风轮和荆棘有各自的材料、形状与效果。

| 蓝图 | 需要 | 行为与取舍 |
| --- | --- | --- |
| 游牧炮垒 | 火炮2 | 停步架炮、围绕阵地回收；最多2座、持续10秒，城堡普通炮击伤害-25% |
| 破阵霰弹 | 火炮2 | 普通齐射增加4枚散弹，单发62%伤害、射程减半；贴近击退前排 |
| 回旋风轮 | 风暴2 | 吞6份物资投出风轮，往返各切一次；回程卷回真实残骸 |
| 奔雷长枪 | 雷电2 | 移动蓄最多3层，停步向最后移动方向贯穿；子弹时间补2层 |
| 连环棘雷 | 荆棘2 | 花园成为一次性地雷，2.6倍伤害；诱敌连爆或用子弹时间引爆 |
| 浮游机库 | 召唤2 | 护卫变成双倍飞行无人机，上限10；攻击更快、单次42%伤害，不能拦弹 |
| 燎原火径 | 烈焰2 | 移动留下火径并点燃花园；普通陨火齐射减少1枚 |
| 霜镜壁垒 | 冰霜2 | 停步架设5秒镜壁，每面反射4发敌弹；普通冰矛齐射减少1支 |

第3次普通选择在具备前置时保证出现蓝图，此后间隔进入候选。第34秒附近出现守卫哨站；击败守卫、吞下哨站再吞蓝图箱，免费三选一。奖励可附带缺少的技能和二阶前置，但仍受3技能槽限制，不消耗普通技能能量。重选优先排除本轮已经见过的卡。技能详情可提前查看蓝图路线；学习蓝图后，升级卡、装备图标与技能说明对应实际形态。

## 组合、吞噬与战斗

总计17个组合。V8增加行军炮阵（火炮2+召唤2）、火羽军团（召唤2+烈焰2）、种荚龙卷（风暴2+荆棘2）、雷火连爆（雷电2+烈焰2）。

- 行军炮阵吞5份战斗残骸储备炮垒，接敌后部署。召唤集结也可储存蓄能，避免空场消耗。
- 火羽军团集结期间改用扇形喷火，无人机继承喷火。雷火连爆需要先点燃，再由雷击引爆。
- 风暴把敌人卷入交战花园；花园可与冰、火、召唤协作，改成棘雷后又需要安排诱敌和爆破时机。
- 城堡四档城体沿用既有设计，武器安装顺序固定；蓝图替换对应挂载，不生成额外的小城堡。

开场22秒以吞堆叠物资为主。之后按攻势和回收间歇推进，敌群在夹击、轰击、甲虫群、护灯编队之间轮换；夹击冲锋会绕侧翼。1:30、4:30、7:30出现精英，10:00出现Boss；特殊对决时普通敌人撤离、停止普通增援，击败精英后有8秒回收空档。事件靠近行进方向生成，沿途有少量物资。

护盾、锚定和体型决定是否能直接吞噬。大型敌人需要战斗破防，残骸成为技能能量与城堡蓄能。子弹时间持续4秒、冷却24秒，主角照常行动，仍会受伤。恢复来自战斗掉包和少量建筑；满血不浪费血包，普通掉包受击杀数、冷却和场上数量限制。远征零件用于基础移动、装甲、吞噬牵引等局外改装。

## 验证与限制

149项规则测试通过；916个词条完成六语占位符校验。通过Chrome正常移动、选卡与子弹时间，实玩两个早期构筑并完成第一场精英。最终素材候选在第49秒实际出现炮垒/风轮/机库三选一，获得机库后又正常升级为8架无人机。日志与图集问题列表为空；桌面本地单次采样60 FPS，不代表真机性能。

**无人机四阶配子弹时间仍能过快击败首个园丁，平衡尚未完成。本轮没有完整手玩到最终Boss，也未逐一人工玩完全部8种形态。** 最后两项UI/重选修正由规则测试、构建验证，未重新跑完整局。详情与截图见 [V8多体系构筑与实玩记录](research/V8-多体系构筑与实玩.html) 和 [验证数据](research/v8-validation.json)。

公开站由Sites原项目更新，权限保持公开。当前环境的公开域名访问被Cloudflare拦截，未绕过；本地同构建实玩和平台部署结果分别记录于 `research/mobile-web-deployment.json`。未声称实体iPhone或公开网络访问已实测。V7的375×667、393×852、852×393安全区及触控记录保留为历史验证，不算V8重测。

## 素材与开发

运行时15张图集。V8机械与元素图集通过内置image_gen生成；原植物草稿保留作设计记录，不在运行时加载。PNG、完整提示词、逐像素无损WebP和格子映射见 [V8素材清单](assets/tactics-v8-manifest.json)。其他城体与敌人资产沿用V7及V6.5清单；未使用参考游戏的原始美术或代码作为运行素材。

```powershell
bun install
bun run i18n:sync
bun test
bun run build
bun run build:mobile
bun run preview:mobile
```
